# Eman Soliman - Frontend Developer Portfolio

A modern, responsive personal portfolio website showcasing my frontend development projects, technical skills, and experience. Built with React, TypeScript, and Tailwind CSS.

## 🚀 Tech Stack

- **Framework:** [React 18](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/) & [Radix UI](https://www.radix-ui.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Email Service:** [EmailJS](https://www.emailjs.com/)

## 🛠️ Features

- 📱 Fully Responsive Design (Mobile, Tablet, Desktop)
- ⚡ Fast performance powered by Vite & SWC
- 🎨 Modern tech color palette & custom gradients
- 📬 Interactive Contact Form with direct email forwarding
- 💼 Projects showcase with live preview and GitHub links

## 💻 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/emanabdelrhman6272/Eman-Soliman-Portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Eman-Soliman-Portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit: `http://localhost:5173` or `http://localhost:8080`.
